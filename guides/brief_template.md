# STANDAR TEMPLATE BRIEF KREATIF: @pmbumri

Dokumen ini adalah format baku pengisian brief kreatif (Flyer, Grafis, Carousel, dan Konten Visual) untuk Tim Komunikasi & Produksi PMB UMRI. Format ini digunakan sebagai acuan penulisan oleh Brand Communications Manager ("Bos") dan AI Creative Showrunner, serta menjadi standar tampilan di Dashboard Studio Hub (`/pmb`).

---

## FORMAT BAKU BRIEF (MARKDOWN / TEXT)

```markdown
### 📋 CREATIVE PRODUCTION BRIEF: [JUDUL KONTEN]
- **ID Konten:** PMB-GRAF-[TAHUNBULAN]-[NO] *(Contoh: PMB-GRAF-202610-01)*
- **Batch / Bulan:** [Oktober 2026 / November 2026 / dst]
- **Kategori:** [Flyer Grafis / Carousel Edukasi / Video Reels / Banner]
- **Status:** [Draft / Siap Eksekusi / In Review / Approved / Published]
- **Target Deadline:** [Hari, Tanggal & Jam]

---

#### 1. SPESIFIKASI MEDIA & CHANNEL
- **Format & Ukuran (Canvas):** 
  - Feed Instagram: 4:5 (1080 x 1350 px) — *Recommended Utama*
  - Square Feed: 1:1 (1080 x 1080 px)
  - Story / TikTok Slides: 9:16 (1080 x 1920 px)
  - Banner Web / Billboard: 16:9 (1920 x 1080 px)
- **Channel Penayangan:** Instagram Feed / Story / TikTok Slides / WhatsApp Blast / X
- **Funnel:** [TOFU (Awareness) / MOFU (Consideration) / BOFU (Conversion)]
